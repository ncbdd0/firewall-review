# 防火墙复习要塞 🔒

> ## ⚠️ 个人使用 · PERSONAL USE ONLY
> 本仓库及站点仅供仓库所有者**个人学习复习使用**，不对外提供任何服务，请勿 fork、部署或二次分发。

个人复习自测站点：背诵模式 / 做题模式 / 知识库（含文档中心）。

## 🔐 访问控制

- 网站地址：<https://ncbdd0.github.io/firewall-review/>
- **需要访问密码**：题库、知识库（含内嵌图片）与文档库全部以 AES-256-CBC 加密存储（PBKDF2 派生密钥，25 万次迭代），打开网站后须输入正确密码方可在浏览器本地解密使用
- 密码与解密过程均不离开浏览器，仓库内**不含任何明文内容**
- 无密码者只能看到锁定页，无法获取题库、知识库与文档内容

## 🧱 功能

- **背诵模式**：题答对照背诵，遮挡自测、掌握度标记、关键词搜索
- **做题模式**：自动判分（选择/填空精确判，名词/简答按关键词命中度），错题重练、战绩统计
- **知识库**：提纲五章 + 实验五个的原文内容，内嵌教材原图（包过滤示例拓扑、屏蔽主机/屏蔽子网结构图等），点击可放大
- **文档中心**：提纲/实验报告等原始文档在线预览与下载（PDF 浏览器原生预览、DOCX 在线转读），支持手动上传老师补充的资料（存于本机浏览器）

## 🛠 技术说明

- 纯原生 HTML / CSS / JavaScript，无后端、无追踪
- 加密：OpenSSL AES-256-CBC + PBKDF2-HMAC-SHA256，浏览器端以 Web Crypto API 解密
- 数据：`data/vault.enc`（加密题库+知识库+图片）、`data/docs.enc`（加密文档库，进入文档中心时才加载）
- DOCX 预览：本地内置 [mammoth.js](https://github.com/mwilliamson/mammoth.js)（无外部 CDN 依赖）
- 手动上传文档存于浏览器 IndexedDB（仅本机可见）
- 响应式设计，兼容手机浏览器

## 📁 目录结构

```
├── index.html                    # 入口（含密码锁定层）
├── styles.css                    # 样式
├── app.js                        # 应用逻辑（解密 + 三模式 + 文档中心）
├── js/vendor/mammoth.browser.min.js  # DOCX 预览库（本地内置）
└── data/
    ├── vault.enc                 # 加密题库/知识库/图片（无密码不可读）
    └── docs.enc                  # 加密文档库（无密码不可读）
```
